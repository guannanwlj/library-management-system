# 测试用例 FP-004：借阅状态规则与错误反馈

测试运行器：`node:test`（通过 `tsx` 执行 TypeScript）。
规则判定为纯函数，使用隔离的 `BookStore` 构造种子数据：
B001 已借出（借阅人 `u1`）、B002 可借、B999 不存在。

## 用户场景（任务卡 §7 验收标准）

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| AC-1 | 重复借出 | B001 已借出 | 判定借阅 | 拒绝，「该图书已借出」，B001 仍 `borrowed` |
| AC-2 | 归还未借出 | B002 可借 | 判定归还 | 拒绝，「该图书未借出」，B002 仍 `available` |
| AC-3 | 编号不存在 | B999 不存在 | 判定借阅或归还 | 拒绝，「图书不存在」 |
| AC-4 | 借阅人标识缺失 | B002 可借但未提供借阅人 | 判定借阅 | 拒绝，「借阅人标识缺失」 |

## 独立验证场景（任务卡 §8）

| 编号 | 场景 | 期望 |
|---|---|---|
| T-1 | 合法借阅 | B002 可借 + 借阅人 `u1` → 允许且 `message` 为 `null` |
| T-2 | 合法归还 | B001 已借出 → 允许且 `message` 为 `null` |
| T-3 | 连续判定幂等 | 同一输入连续两次判定结果相同（纯函数） |
| T-4 | 拒绝后状态不变 | 每次拒绝后 `store.find` 的状态与借阅人保持原值 |
| T-5 | 便捷包装读取存储 | `checkBorrow` / `checkReturn` 内部经 `find` 取状态并作出同样判定 |

## 边界与错误路径

| 编号 | 场景 | 期望 |
|---|---|---|
| E-1 | 借阅人标识为 `undefined` | 借阅可借图书 → 拒绝「借阅人标识缺失」 |
| E-2 | 借阅人标识为 `null` | 借阅可借图书 → 拒绝「借阅人标识缺失」 |
| E-3 | 借阅人标识为空串 / 纯空白 | 借阅可借图书 → 拒绝「借阅人标识缺失」 |
| E-4 | 编号不存在且未提供借阅人 | 借阅 B999 → 优先「图书不存在」 |
| E-5 | 已借出且未提供借阅人 | 借阅 B001 → 优先「该图书已借出」 |
| E-6 | 未借出的图书携带残留借阅人 | 归还 B002 → 「该图书未借出」 |
| E-7 | 归还时借阅人标识不影响判定 | 归还 B001（携带借阅人）→ 允许 |
| E-8 | 使用最简状态对象（§6 Mock） | `{ status, borrower }` 字面量即可判定，不依赖完整 `Book` |

## 文案逐字校验

拒绝文案必须逐字等于契约固定值，测试直接与
`BorrowRuleMessages` 及中文字面量双重比对，防止改动走样。

## 验收映射
- AC-1 → 用例 `AC-1: borrow of a borrowed book is rejected`
- AC-2 → 用例 `AC-2: return of an available book is rejected`
- AC-3 → 用例 `AC-3: an unknown id is rejected for both operations`
- AC-4 → 用例 `AC-4: borrow without a borrower is rejected`
- T-1..T-5、E-1..E-8 见对应用例。
