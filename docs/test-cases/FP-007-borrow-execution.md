# 测试用例 FP-007：借出执行与状态变更

测试运行器：TypeScript 用 `node:test`（经 `tsx`），Python 用 `unittest`。
两个运行时各自使用隔离的内存集合构造任务卡 §6 种子数据：
B001 可借；B002 已借出（`borrower="u1"`）；B999 不存在。

## 用户场景（任务卡 §7 验收标准）

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| AC-1 | 成功借出 | B001 可借 | `borrow(B001, u1)` | 成功；B001 `status=borrowed`、`borrower=u1` |
| AC-2 | 重复借出 | B002 已借出（`u1`） | `borrow(B002, u1)` | 拒绝，「该图书已借出」；B002 状态与借阅人不变 |
| AC-3 | 编号不存在 | B999 不存在 | `borrow(B999, u1)` | 拒绝，「图书不存在」；集合不变 |
| AC-4 | 借阅人缺失 | B001 可借但借阅人为空 | `borrow(B001, '')` | 拒绝，「借阅人标识缺失」；B001 仍可借 |

## 独立验证场景（任务卡 §8）

| 编号 | 场景 | 期望 |
|---|---|---|
| T-1 | 结果契约 | 返回值含布尔 `ok` 与字符串 `message` |
| T-2 | 成功写入穿透集合 | 借出后 `find` / `listAll` 均反映新状态与借阅人 |
| T-3 | 自由文本原样保存 | 含首尾空白/符号的借阅人原样写入（FP-003 D3） |
| T-4 | 拒绝不改集合 | 三类拒绝后 `listAll()` 与调用前完全一致 |

## 边界与错误路径

| 编号 | 场景 | 期望 |
|---|---|---|
| E-1 | 借阅人为 `null` | 可借图书 → 拒绝「借阅人标识缺失」，状态不变 |
| E-2 | 借阅人为 `undefined`（TS） | 同上（Python 以 `None` 表达，见 E-1） |
| E-3 | 借阅人为纯空白 | 同上 |
| E-4 | 编号不存在且借阅人缺失 | 优先「图书不存在」（FP-004 判定优先级） |
| E-5 | 已借出且借阅人缺失 | 优先「该图书已借出」 |
| E-6 | 同一本书连续借出两次 | 第二次拒绝「该图书已借出」，借阅人仍为首次值 |
| E-7 | 归还后再借出 | 归还（`setStatus` 置可借）后可再次借出成功 |
| E-8 | 成功文案常量 | `BORROW_SUCCESS_MESSAGE` 逐字为「借阅成功」 |
