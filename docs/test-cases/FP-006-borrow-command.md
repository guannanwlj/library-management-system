# 测试用例 FP-006：借阅命令入口

被测对象：
- TypeScript：`src/features/borrow-command.ts`（解析参数、校验、调用
  FP-007 `borrow`、返回结果文本）。
- Python：`library/borrow_command.py`（挂载到真实 FP-005 分发器，调用
  `library.borrow_books.borrow`）。

运行方式：
- TS：`npm test`
- PY：`python3 -m unittest discover -s tests`

种子数据（任务卡 §6）：B001 可借；B002 已借出（`borrower="u1"`）；
B999 不存在。

## 用户场景（任务卡 §7 验收标准）

| 编号 | 场景 | Given | When | Then |
|---|---|---|---|---|
| AC-1 | 成功借阅 | B001 可借、借阅人 `u1` | `borrow B001 u1` | 触发借出处理，输出 `借阅成功`，B001 `status=borrowed`、`borrower=u1` |
| AC-2 | 缺借阅人 | 输入 `borrow B001` | 借阅 | 拒绝，输出 `借阅人标识缺失`；不调用借出执行，B001 保持可借 |
| AC-3 | 已借出透传 | B002 已借出（`u1`） | `borrow B002 u1` | 输出拒绝文案 `该图书已借出`（透传 FP-007 结果） |

## 独立验证场景（任务卡 §8）

| 编号 | 场景 | 期望 |
|---|---|---|
| T-1 | 正常参数调用 | 处理器把解析出的 `(bookId, borrower)` 原样交给执行函数，返回其 `message` |
| T-2 | 缺参拒绝 | 参数不足两个 / 借阅人纯空白 → `借阅人标识缺失`，执行函数零调用 |
| T-3 | 已借出透传 | 执行函数返回 `{ok:false, message:'该图书已借出'}` → 入口返回同文案 |
| T-4 | 注册适配 | `register*` 以 `borrow` 为名挂载处理器，分发面可命中 |
| T-5 | 真实分发链路 | 通过 FP-005 分发器 `dispatch(['borrow', ...])` 驱动真实 FP-007，状态随之变化 |
| T-6 | 端到端冒烟 | `python3 -m library borrow B001 u1` 输出 `借阅成功`；缺参输出 `借阅人标识缺失` |

## 边界与错误路径

| 编号 | 场景 | 期望 |
|---|---|---|
| E-1 | 借阅人为空串 / 纯空白 | 拒绝 `借阅人标识缺失`，不调用执行 |
| E-2 | 参数为零个 / 一个 | 拒绝 `借阅人标识缺失` |
| E-3 | 编号不存在（B999，含空编号） | 透传 `图书不存在` |
| E-4 | 多余 token | 忽略，只取前两个 token |
| E-5 | 借阅人含首尾空白/符号 | 原样传给执行层（不 `trim`，FP-003 自由文本） |
| E-6 | 拒绝路径零副作用 | 缺参调用后集合完全不变 |
| E-7 | 默认绑定单例 | 不注入 store 时读写共享集合（测试自行清理） |

## 文案逐字校验

入口不新增业务文案：缺参为 `借阅人标识缺失`；其余成功 / 拒绝文案
逐字等于 FP-004 / FP-007 契约值（`借阅成功`、`图书不存在`、
`该图书已借出`）。
