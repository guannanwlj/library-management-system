# 测试用例：FP-005 命令行入口框架

被测对象：`library.cli.CommandDispatcher` 及模块级默认分发器。

术语：假处理器＝记录被调用参数的测试替身，接受 `list[str]`、
返回固定字符串。

## 分发命中（验收标准 7.1–7.3）

| # | 场景 | 输入 | 期望 |
|---|---|---|---|
| T01 | borrow 分发 | `["borrow", "B001", "u1"]` | borrow 假处理器被调用一次，入参 `["B001","u1"]` |
| T02 | return 分发 | `["return", "B001"]` | return 假处理器被调用一次，入参 `["B001"]` |
| T03 | list 分发 | `["list"]` | list 假处理器被调用一次，入参 `[]` |
| T04 | 处理器返回值透传 | 任一子命令，假处理器返回 `"OK-BORROW"` | `dispatch` 返回 `"OK-BORROW"` |
| T05 | 多参数透传 | `["borrow", "B001", "u1", "extra"]` | 假处理器入参 `["B001","u1","extra"]` |

## 未知与边界（错误处理路径）

| # | 场景 | 输入 | 期望 |
|---|---|---|---|
| T06 | 未知子命令 | `["hack", "x"]` | 返回 `未知命令`，无任何处理器被调用 |
| T07 | 空输入 | `[]` | 返回 `未知命令` |
| T08 | 未注册的已登记命令 | 仅注册 borrow，输入 `["return","B001"]` | 返回 `未知命令` |

## 注册 / 挂载点

| # | 场景 | 期望 |
|---|---|---|
| T09 | 注册后即可分发 | 注册 borrow 后 `["borrow","B001","u1"]` 命中 |
| T10 | 重复注册覆盖 | 同名注册两次，分发命中第二个处理器 |
| T11 | 非可调用处理器 | `register("x", 123)` 抛 `TypeError` |
| T12 | 空命令名注册 | `register("", fn)` 抛 `ValueError` |
| T13 | 便捷注册函数 | 模块级 `register` 挂载到默认分发器，`dispatch` 命中 |

## 统一输出与占位（验收标准 7.4 及 §6）

| # | 场景 | 期望 |
|---|---|---|
| T14 | 统一输出 | `run(argv, out=StringIO)` 把结果文本写入 out，并返回同样文本 |
| T15 | 默认占位处理器 | 默认分发器对 borrow / return / list 均返回 `命令已受理` |
| T16 | 占位可被覆盖 | 默认分发器 register 后分发命中新处理器 |
| T17 | 无认证 / 无授权 | 直接分发即命中处理器，无任何前置身份校验（处理器未被任何守卫拦截） |

## 运行方式
```
python3 -m unittest discover -s tests -v
```
